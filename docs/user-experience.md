# 用户流程与协作界面

状态：v0.1交互合同，尚无产品界面。覆盖R-01至R-14，具体字段和权限以[领域模型](domain-model.md)、[API](api-and-events.md)为准。

## 1. 信息架构

Web首版提供：个人/团队Space切换、员工目录、项目群与私聊、任务列表与详情、产物目录、Creator、设备与连接、审批/审阅、运行状态与预算。可以复用简单侧栏和详情页，不要求实现通用IM的通讯录、音视频、消息撤回体系。

每个员工卡展示职责、所有者类型、默认版本、可用位置与能力摘要；设备在线状态与员工身份存在状态分开展示，不能把离线设备标成数字员工已被删除。

## 2. 创建并配置员工

用户向Creator描述需求。Creator将职责、输入、交付物、能力、环境限制、成本和验收整理为可编辑草稿；未确定事项通过有边界的提问补齐。

已有能力能满足时，显示装配清单和prompt/skills差异。缺口存在时，显示将调用哪类编码/领域专员、生成什么构件、在哪里测试。编写代码本身不表示已完成发布。

用户可运行测试并查看具体结果；发布动作生成不可变版本。实例化时再选择个人/团队归属、账户连接、实际可用资源与授权。部署委派角色绑定到具体员工，定义本身保留可复用角色别名。

## 3. 发布本地或云端任务

任务表单收集：目标、负责人、输入引用、验收条件、预算、执行位置、最终审阅方式。local/cloud必须在发布前明确；能力不兼容时给出原因，不自动换位置或扩大权限。

local显示目标设备和授权根目录，本地路径由daemon解析。cloud显示云端可访问的输入与工具；仅本机存在的文件不能假装已经在云端。上传或分享是单独明确的动作。

点击发布后取得task_id，界面可关闭。云端任务继续执行，重新打开时从持久状态和事件加载；本地设备离线则显示等待设备及可操作入口。

## 4. 拉群并启动统筹

创建团队项目群，邀请研究员、分析员、统筹员工与自己的个人助手。个人助手加入群需要owner同意；加入只建立路由/可见性，私有资料共享另行授权。

人通过@或任务发布入口安排工作；默认仅负责人/被@成员响应。统筹员工展示简要分工与任务卡，真正派发后可看到子任务负责人、状态、输入、预算和产物，而不是只有“已经安排”。

来自个人Space的工作通过DelegationRequest受理；群里只看到被批准的状态与成果，不展示私人session、账号和其他私聊。

## 5. 任务详情与等待

| 状态／原因 | 展示与操作 |
| --- | --- |
| queued | 负责人、位置、排队情况；可暂停或取消 |
| running | 当前阶段、工具安全摘要、预算、子任务与产物；可请求暂停或取消 |
| waiting_device | 设备不可用，等待原设备；可重新连接、取消或另建明确云任务 |
| waiting_approval | 具体动作、参数/资源范围、期限、风险摘要及批准/拒绝；不默认执行 |
| waiting_input | 需要补充的具体资料及安全上传/引用入口 |
| waiting_dependency | 依赖任务和受限状态；失败时展示处置选项 |
| user_paused | 已在安全边界暂停；恢复或取消 |
| recovery_required | 动作结果待核对；显示证据和已完成/未执行/放弃入口，不提供盲目重发 |
| review | 具体产物版本、验收项、接受或返工反馈 |
| succeeded/failed/cancelled | 最终事实、已生成成果、原因与用量；需要重试时创建新Task |

pause请求发出到达到安全边界之间显示“正在暂停”，不能立即显示“已停止”。工具在途时取消是尽力终止，已发生操作继续留下事实记录。状态细则与输入解除操作以主合同为准。

## 6. 成果、审阅与发布

产物卡显示文件类型、版本、来源任务、内容hash和允许的共享范围；预览不可信HTML时隔离origin。数值结果有计算方法或代码/输入来源，研究报告包含可核对引用。

最终任务默认人工review。接受指定版本后成功；返工追加明确反馈并重新排队，不静默更改目标或权限。工具外发审批与成果接受分开，不能把审阅报告等同批准发送邮件。

Creator版本列表区分草稿、已发布与当前默认；修改草稿后验证状态失效。回滚仅改变新任务默认版本，进行中任务展示所绑定旧版本。

## 7. 产品状态透明度

在线、离线、等待、失败、未知和未验证分别显示。界面不得把模型流式输出当作任务成功，把配置生成当作工具可用，或把模拟云演示当作云部署完成。高频token/终端日志可折叠；主要视图保留用户能判断进展与结果的事实。

首次使用先完成一个小任务和一种受限能力授权，再扩展角色和账号。测试/开发环境和真实账号环境使用清楚的标记，避免样例变成意外外部操作。
